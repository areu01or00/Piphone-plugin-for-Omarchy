# Discord playbook
- The empty composer shows "Record Voice Message"; after text it becomes the Send control — pass that current ref to phone_post.
- Search: type `from:` and the display name to filter a person's messages; author-filter pickers may omit some display names.
- Prefer reading the channel feed over search when a handful of messages is enough.
- Confirm the channel-name marker (e.g. `general-chat, Member List`) before posting.
- `phone_type` on the search field: tap, wait for the keyboard, clear, then insert; abort on mismatch.
